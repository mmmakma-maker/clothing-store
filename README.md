# متجر الملابس النسائي

مشروع متجر نسائي تجريبي كامل:
- تسجيل مستخدم وتاجر
- إضافة وحذف المنتجات
- عرض المنتجات مع تفاصيلها
- فلترة المنتجات والبحث المباشر
- سلة مشتريات مع تعديل الكمية
- تقييم المنتجات (نجوم + تعليق)
- منتجات مشابهة لكل منتج
- تحسين تجربة المستخدم (hover، نفاد الكمية، عرض المنتجات الجديدة أولاً)

## طريقة التشغيل
1. افتح `index.html` في أي متصفح حديث.
2. لتسجيل التاجر، استخدم كلمة المرور: `1234`
3. جميع البيانات تُخزن مؤقتًا في `localStorage` بالمتصفح.
